# Tell a Whole Story in 32 Characters

A Wi-Fi network name of exactly 32 characters, for the make.fun bounty
[Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

> Divorced: she got house, me WiFi

`main.ts` writes that single name to `/output/entry.txt`. One word,
"Divorced", brings the marriage, the split and the settlement; the
settlement is the joke — she got the house, the narrator got the Wi-Fi,
and a passer-by reading the network list can fill in the rest.
